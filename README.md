## ✨ قابلیت‌ها

- **🎯 پنل ۲۵ گزینه‌ای** با رابط فارسی
- **🧠 ۴ موتور مستقل:** due, knowledgeforge, sacred, pqasd
- **🤖 CORTEX** — ایجنت خودمختار
- **🔗 CORTEX Chain** — چند-مرحله‌ای
- **🧠 MIND** — هوشیاری درونی
- **🩺 خودترمیمی:** selfcare, autoheal, selfrun
- **🧪 تستر:** panel_test, deep_test, health
- **🏥 Doctor** — چک سلامت
- **🌐 داشبورد وب** روی localhost:8090

## 🚀 نصب

git clone git@github.com:hossiensoldier-collab/evoscanner.git
